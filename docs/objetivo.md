# Trebbol - Visión del Producto y Sistema de Comunicación

# ¿Qué es Trebbol?

Trebbol es una plataforma multiservicio que conecta Vecinos, Freelancers y Empresas en un único ecosistema digital.

Su propósito es permitir que cualquier persona pueda resolver necesidades de comercio, contratación de servicios, empleo y promoción de negocios sin tener que utilizar múltiples aplicaciones.

Trebbol integra en una sola experiencia:

* Marketplace de productos.
* Marketplace de servicios profesionales.
* Bolsa de empleo.
* Sistema de publicidad.
* Mensajería en tiempo real.
* Reputación y confianza.
* Wallet y pagos digitales.

Trebbol busca convertirse en el punto de encuentro económico de las comunidades locales.

---

# Lo que Trebbol NO es

Trebbol no es:

* Una red social.
* Una aplicación de domicilios.
* Una bolsa de empleo tradicional.
* Un marketplace tradicional.
* Una plataforma freelance tradicional.

Trebbol es un ecosistema integral que combina comercio, servicios profesionales, empleo y publicidad dentro de una misma plataforma.

---

# Visión

Crear una comunidad digital donde vecinos, profesionales y empresas puedan conectarse de manera sencilla, segura y eficiente para generar oportunidades económicas.

La plataforma debe fomentar:

* La economía local.
* La confianza entre usuarios.
* La competencia justa.
* El acceso a oportunidades para todos.

# Sistema de Comunicación

La comunicación es uno de los pilares principales de Trebbol.

No se trata únicamente de un chat tradicional.

Cada conversación existe porque hay una oportunidad comercial, profesional o laboral detrás.

La comunicación siempre debe estar relacionada con una actividad dentro de la plataforma.

---

# Escenario 1: Compra y Venta de Productos

Un usuario encuentra un producto dentro del Marketplace.

Antes de comprar puede comunicarse directamente con el vendedor para:

* Resolver dudas.
* Solicitar información adicional.
* Negociar condiciones.
* Coordinar la entrega.

La conversación ocurre únicamente entre comprador y vendedor.

---

# Escenario 2: Solicitud de Servicios

Este es uno de los elementos más importantes y diferenciadores de Trebbol.

Un vecino necesita un servicio.

Por ejemplo:

* Podar un árbol.
* Pintar una vivienda.
* Realizar una instalación eléctrica.
* Reparar una tubería.
* Hacer mantenimiento de jardines.

El vecino crea una solicitud explicando su necesidad.

El sistema analiza la solicitud y selecciona automáticamente cinco freelancers que cumplan con los criterios adecuados.

La selección busca generar competencia justa.

Por ejemplo:

* Dos freelancers con plan profesional.
* Dos freelancers con reputación media o baja.
* Un freelancer nuevo o con plan gratuito.

Todos son invitados a una misma conversación.

---

# Sala de Cotización

La conversación funciona como una sala de propuestas.

Dentro de ella:

* El vecino explica lo que necesita.
* Los freelancers realizan preguntas.
* Los freelancers presentan ofertas.
* Los freelancers indican tiempos de ejecución.
* Los freelancers explican qué incluye el servicio.

El vecino puede comparar todas las propuestas dentro de un mismo espacio.

Esto evita tener múltiples conversaciones separadas.

También permite que nuevos profesionales tengan oportunidades reales de competir.

---

# Selección del Profesional

Cuando el vecino encuentra la mejor propuesta puede seleccionar al freelancer que desea contratar.

Una vez seleccionado:

* Finaliza el proceso de comparación.
* Se cierra la etapa de cotización.
* Se crea una conversación privada entre ambas partes.

A partir de ese momento pueden coordinar el trabajo directamente.

---

# Escenario 3: Empleo

Una empresa publica una vacante.

Un freelancer o profesional aplica a la oferta.

Una vez realizada la aplicación se habilita una conversación entre ambas partes.

Esta comunicación permite:

* Resolver dudas.
* Solicitar información.
* Compartir documentos.
* Coordinar entrevistas.
* Avanzar en el proceso de selección.

---

# Comunicación en Tiempo Real

La experiencia de comunicación debe sentirse inmediata y natural.

Los usuarios deben poder:

* Enviar mensajes.
* Compartir imágenes.
* Compartir documentos.
* Ver cuándo alguien está escribiendo.
* Saber cuándo un mensaje fue leído.
* Recibir notificaciones.
* Consultar conversaciones anteriores.

---

# Principio Fundamental

La comunicación en Trebbol no existe como una función independiente.

Siempre nace de una oportunidad real dentro de la plataforma:

* Un producto.
* Un servicio.
* Una vacante.
* Una contratación.

De esta manera cada conversación tiene un propósito claro y aporta valor al ecosistema.

---

# Modelo de Negocio

Trebbol opera bajo un modelo Freemium.

Existen diferentes planes para cada tipo de usuario.

Los usuarios pueden acceder a funcionalidades adicionales mediante:

* Suscripciones.
* Publicidad.
* Publicaciones destacadas.
* Servicios promocionados.
* Vacantes destacadas.

---

# Objetivo Final

Trebbol busca convertirse en el ecosistema digital local donde vecinos, freelancers y empresas puedan comprar, vender, contratar, trabajar, promocionarse y comunicarse desde una única plataforma, generando nuevas oportunidades económicas para toda la comunidad.
